# Контент-завод

Навык производит готовые офферы по логистике из Китая под нужную площадку и аудиторию. Не теория — рабочий текст, который можно публиковать.

## Что у тебя есть

Папка `git_hub/` рядом с этим файлом — источник правды. Читай её, не выдумывай структуру.

- `templates/offer-template.md` — универсальный каркас оффера
- `templates/target-offers.md` — формат таргета
- `templates/context-offers.md` — формат контекста
- `templates/seo-offers.md` — формат SEO (title/description/H1)
- `audiences/urlica.md`, `sellers.md`, `optoviki.md` — боли и язык каждой аудитории
- `content-log.md` — журнал публикаций
- `publish-checklist.md` — чек-лист перед публикацией

## Когда запускать навык

Когда просят: «напиши оффер», «текст для таргета/контекста/SEO», «посадочную страницу», «оффер под селлеров/юрлиц/оптовиков», «пополнить контент-завод».

Не запускать для: аналитики метрик (CPL/CAC) — это отдельная задача аналитика, не контент.

## Алгоритм работы

1. **Уточни вводные.** Из запроса выдели: площадку (таргет/контекст/SEO), аудиторию (юрлица/селлеры/оптовики), тему оффера. Если чего-то нет — спроси коротко, одним списком.
2. **Прочитай карточку аудитории** из `audiences/`. Оффер пишется под боли этой аудитории, а не общий.
3. **Возьми формат** из `templates/` под нужную площадку. Соблюдай лимиты символов:
   - таргет: заголовок ≤ 40, текст 2–4 предложения
   - контекст: заголовок 1 ≤ 56, заголовок 2 ≤ 30, текст ≤ 81
   - SEO: title ≤ 60, description ≤ 160
4. **Напиши оффер.** Конкретика, цифры, одно действие в CTA. Без воды.
5. **Проверь по чек-листу** из `publish-checklist.md`.
6. **Запиши в журнал.** Добавь строку в `content-log.md` (дата, площадка, аудитория, оффер, статус «черновик»).

## Правила оффера

- **Один оффер = одна площадка + одна аудитория.** Не смешивай.
- **Цифры конкретные:** срок в днях, цена в $/кг или ₽, порог объёма. Не «скоро», не «дёшево».
- **CTA — конкретное действие:** «Рассчитать стоимость», «Получить тариф», «Оставить заявку». Не «узнать больше».
- **Честность по границам:** что НЕ делаем или при каких условиях. Это отсекает нецелевые лиды до старта.
- **Язык аудитории:** селлерам — «FBO, маркировка, от 1 коробки»; юрлицам — «НДС, безнал, закрывающие документы»; оптовикам — «ставка за кг, фиксация на 3 месяца». Не путать.

## Что НЕ делать

- Не выдумывать цифры. Если реальных данных нет — ставь заглушку `__` и помечай «проверить перед запуском».
- Не удалять и не переименовывать существующие офферы в `templates/` — только добавлять новые.
- Не пушить в remote и не трогать файлы вне `git_hub/`.
- Не писать теорию копирайтинга. Только рабочий текст.

## Формат ответа

Готовый оффер в формате площадки. После — одной строкой: что добавлено в `content-log.md`. Без воды и пояснений очевидного.
