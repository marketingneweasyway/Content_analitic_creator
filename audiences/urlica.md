# Аудитория: Юрлица

Импортёры, B2B-компании, закупающие товар из Китая для перепродажи или производства.

## Профиль
- Компании с расчётным счётом, НДС, закупающие оптом
- Решение принимает закупщик/коммерческий директор, не владелец
- Важно: закрывающие документы, оплата по безналу, предсказуемая цена

## Боли
- Цена «в процессе» растёт: доплаты за вес-объём, СВХ, хранение
- Срыв сроков → простой производства / пустые полки
- Проблемы с таможней: корректировка стоимости, штрафы, досмотры
- Нет закрывающих документов для бухгалтерии
- Нецелевой лид: «физик» ищет посылку, а не контейнер

## Что продаём им
- Доставка «под ключ»: от фабрики до склада с фиксированной ценой
- Таможенное оформление под их код ТН ВЭД
- Склад консолидации в Китае для сбора от разных поставщиков
- Оплата по безналу с НДС, закрывающие документы

## О чём писать в офферах
- Фиксация цены в договоре, без доплат
- Срок в днях, не «скоро»
- НДС, безнал, закрывающие документы
- Штраф за срыв срока по нашей вине

## Чего избегать
- «Уникальный», «лучший», «профессиональный» — пустые слова
- Обещаний без цифр
- Призывов «узнать больше» — конкретное действие
